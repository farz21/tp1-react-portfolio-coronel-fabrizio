# Portfolio Personal Multipágina en React

**Nombre y Apellido:** Fabrizio Gabriel Coronel Gordillo
**Comisión:** 5

## Descripción
Portfolio personal desarrollado como Trabajo Práctico Nº 2 para la materia Programación 4 (UTN). Es una aplicación multipágina (SPA) construida con React que muestra perfil profesional, habilidades, proyectos y formas de contacto. El proyecto evolucionó del TP1, incorporando ahora navegación dinámica sin recarga de página a través de un menú lateral utilizando React Router DOM, manteniendo su diseño moderno tipo Glassmorphism.

## Tecnologías utilizadas
- React + Vite
- React Router DOM (para enrutamiento y navegación)
- CSS3 (Diseño responsivo y Glassmorphism)
- EmailJS (para el formulario de contacto funcional)
- Devicon (para iconos de tecnologías)

## Cómo ejecutar el proyecto localmente
1. Clonar el repositorio: `git clone https://github.com/farz21/tp1-react-portfolio-coronel-fabrizio`
2. Instalar dependencias: `npm install`
3. Iniciar el servidor: `npm run dev`
