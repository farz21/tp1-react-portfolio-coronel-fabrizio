## Estudiante

## Descripción
Portfolio personal desarrollado como Trabajo Práctico Nº 1 para la materia Programación 4 (UTN). Es una Single Page Application construida con React que muestra perfil profesional, habilidades, proyectos y formas de contacto, con un diseño moderno tipo Glassmorphism.

## Tecnologías utilizadas
* React + Vite
* CSS3
* EmailJS para formulario de contacto
* Devicon para iconos

## Cómo ejecutar el proyecto localmente
1. Clonar el repositorio: `git clone https://github.com/farz21/tp1-react-portfolio-coronel-fabrizio`
2. Instalar dependencias: `npm install`
3. Iniciar el servidor: `npm run dev`
